## Start with a working editor

<Steps>
<Step>

**Install.** Check [requirements and installation](/docs/getting-started).

</Step>
<Step>

**Mount.** Connect the protected API and studio with [Next.js setup](/docs/nextjs-setup).

</Step>
<Step>

**Build.** Create a native page using the [studio workflow](/docs/studio).

</Step>
<Step>

**Ship.** Add [preview and public rendering](/docs/publishing), then verify save and publish separately.

</Step>
</Steps>

<Callout title="What you need">
The setup guide assumes you already have host authentication, PostgreSQL and Redis. OpenRouter is optional and only needed for AI generation. Start with a local project before connecting production data.
</Callout>
